# GAS のセットアップ手順（学びメモ用）

学びメモの保存先は、健康アプリとは**別のスプレッドシート・別の GAS** です。
健康アプリのスプレッドシート（「あお健康管理AP」）には何も足しません。

所要時間は 10 分ほど。PC の Chrome で行います。

## A. スプレッドシートと GAS を作る

1. Google ドライブを開き、「新規」→「Google スプレッドシート」→「空白のスプレッドシート」。
2. 左上の名前を **「あお学びメモAP」** に変える（名前は自由。健康アプリのものと見分けられれば OK）。
3. メニューの「拡張機能」→「Apps Script」を開く（別のタブでエディタが開く）。
4. エディタ左上の「無題のプロジェクト」を押して、名前を **「あお学びメモGAS」** に変える。
5. 最初から書いてある `function myFunction() { }` をすべて消す。
6. このリポジトリの `gas_code.js` の中身を**丸ごと**コピーして貼り付ける。
   - GitHub で `gas_code.js` を開き、右上の「Copy raw file」（四角が2つ重なったボタン）を押すと全文をコピーできます。
7. フロッピーのボタン（プロジェクトを保存）を押す。

## B. 合言葉を決めて、GAS に設定する

8. 合言葉を作る（健康アプリとは**別のもの**にする）。Claude Code の入力欄で次を実行すると、
   画面には表示されず、クリップボードに入ります（32 は文字数。24 以上なら自由）。

   ```
   ! LC_ALL=C tr -dc 'A-Za-z0-9' < /dev/urandom | head -c 32 | pbcopy
   ```

9. **他のものをコピーする前に**、Google パスワードマネージャー（passwords.google.com）に
   「あお学びメモ合言葉」として保存する。
10. Apps Script エディタの左の歯車「プロジェクトの設定」を開く。
11. いちばん下の「スクリプト プロパティ」→「スクリプト プロパティを追加」。
12. プロパティ＝ `SYNC_TOKEN` ／ 値＝合言葉 を貼り付け、「スクリプト プロパティを保存」。
    - ⚠️ 値の前後に空白や改行が入っていないか、目で確かめる（GAS 側は空白を取り除きません）。

## C. デプロイして URL を控える

13. エディタ右上の「デプロイ」→「新しいデプロイ」。
14. 「種類の選択」の歯車 →「ウェブアプリ」。
15. 次のように設定する。
    - 説明：`manabi v1`
    - 次のユーザーとして実行：**自分**
    - アクセスできるユーザー：**全員**
16. 「デプロイ」を押す。はじめての場合は「アクセスを承認」→ 自分のアカウントを選ぶ →
    「詳細」→「（安全ではないページ）に移動」→「許可」。
17. 表示された **ウェブアプリの URL**（`https://script.google.com/macros/s/…/exec`）をコピーする。
18. その URL を、パスワードマネージャーの「あお学びメモ合言葉」のメモ欄にも控えておく（スマホで使うため）。
19. 確認：その URL を Chrome の新しいタブで開く。
    **「あおの学びメモ GAS は動いています（manabi v1）…」** と出れば成功。
    - この画面にデータは出ません（データの読み書きはアプリからだけ行います）。

## D. アプリに設定する（PC → スマホの順）

20. 学びメモのアプリを開く → 右上の ⚙️ →「同期の設定」に URL と合言葉を貼り付け →「保存して同期する」。
21. 画面の上（タイトルの下）に「同期済み」と出れば OK。黄色の「同期はまだ設定されていません」が消えます。
22. スプレッドシートに戻ると、`data` というタブができていて、`memos`・`categories` の行が入っています。
23. スマホでも同じ（20〜21）。スマホでは Chrome の新しいタブで passwords.google.com を開き、
    URL と合言葉をコピーしてからアプリに戻って貼り付けます。

## あとで GAS のコードを変えたとき

- エディタに貼り直して保存 →「デプロイ」→「デプロイを管理」→ 鉛筆 → バージョン「新バージョン」→「デプロイ」。
  （「新しいデプロイ」を選ぶと URL が変わってしまうので、必ず「デプロイを管理」から。）
- エディタを変えたら、リポジトリの `gas_code.js` も同じ内容にする。

## 注意

- スプレッドシート「あお学びメモAP」を**ゴミ箱に入れない**（GAS の本体がこの中にあり、入れると同期が止まります）。
  ドライブでスター（重要マーク）を付けておくと安心です。
- 合言葉の値・URL は、チャットやメモ類・このリポジトリには書かない。
- `auth_log` というタブができていたら、合言葉の間違いの記録です（1時間ごとに1行）。
  身に覚えのない時間帯に増えていたら、合言葉を変えます（B の手順で作り直し、GAS → PC → スマホの順に貼り替え。再デプロイは不要）。
